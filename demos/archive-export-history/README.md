# Reddit 归档 · 导出历史 Demo

一个可独立运行的静态 Demo，用来演示 Reddit 归档工具的「导出历史」页面：

- 12 条本地合成的导出记录（导出时间、subreddit、帖子数、状态、扣分）
- 按 subreddit 与状态筛选，支持组合筛选
- 点击「查看详情」打开详情对话框，查看导出范围、用时、扣分明细与备注
- 筛选无结果时显示明确空态，并可一键清除筛选
- 390px 移动端可用，无横向滚动

> 所有记录均为合成数据，不包含真实 Reddit 内容；所有交互只在浏览器内完成，没有后端请求，也不会上传任何数据。

## 运行

页面使用 ES Module，需要通过 HTTP 访问，不能直接双击 `index.html`。在本目录执行：

```bash
cd demos/archive-export-history
python3 -m http.server 8000
```

然后打开 <http://localhost:8000/>。也可以使用任意静态文件服务器，无需安装依赖。

## 验证

```bash
cd demos/archive-export-history
node verify.mjs
```

`verify.mjs` 只使用 Node 内置模块，覆盖：

- 数据完整性、字段类型、ID 唯一性
- 扣分明细合计与状态口径
- subreddit / 状态 / 组合筛选、未知筛选、空结果组合
- 汇总数量、帖子数与扣分
- 北京时间、数字、用时、导出范围格式化
- subreddit 选项去重排序与排序函数不修改入参

浏览器人工检查清单：

- 默认显示 12 条记录，汇总为 12 次 / 9,015 篇 / 101 分
- 选择 `r/webdev` 后显示 2 条；再选择「失败」只显示 `exp-1034`
- 选择 `r/books` + 「失败」显示空态，空态文案点明当前筛选
- 点击「查看详情」打开对话框，Esc、关闭按钮、点击遮罩均可关闭
- 390px 宽度下筛选、列表、详情均可操作，且无横向滚动

## 数据口径

每条记录包含导出时间（UTC+8）、subreddit、帖子数、状态、扣分；详情额外提供导出范围、用时、扣分明细与备注。

| 状态 | 含义 | 扣分 |
| --- | --- | --- |
| 已完成 | 帖子与附件均归档成功 | 0 |
| 部分完成 | 存在少量缺失或跳过的内容 | > 0 |
| 失败 | 导出中断，记录不完整 | > 0 |

累计扣分是当前筛选结果中所有记录扣分之和。
